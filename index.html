QA com visão de engenharia

Sou Rafael Orleães, QA analítico atuando sozinho como dono da qualidade num produto de healthtech regulado (CFM · ANS · LGPD). Qualidade, pra mim, não é etapa — é propriedade do sistema inteiro.

Meu trabalho é API-first: testo o backend em C#/ASP.NET e SQL Server, construí um harness próprio com cache de token por role e asserções em banco, automatizo E2E com Playwright, rodo carga com k6 e faço testes de contrato e de autorização. Transformo cards do Jira em runbooks executáveis.

Princípio central: evidência honesta acima de métrica inflada. Prefiro mostrar método, decisão e rigor a exibir número que não se sustenta.

Trabalho técnico

Detalhes sanitizados por confidencialidade (LGPD). O que está aqui é o método e a arquitetura, não dados do produto.

API · Harness
Harness de API autenticado

Cliente HTTP com cache de token por role, asserções diretas em SQL Server, runner declarativo de fluxos e fixtures Playwright. Slots de endpoint deixados como TODO — nada inventado.

typescript playwright sql-server http-client
Processo · Runbook
Do card ao teste executável

Leio o card, derivo o critério de aceite, monto pré-condições, dados e tokens por role, e sequencio o teste scriptado antes do exploratório.

jira rovo runbook sql
API · Contrato & Segurança
Testes de contrato e autorização

Validação de schema, ProblemDetails (RFC 9457) e checagem de autorização por role — IDOR, acesso sem credencial e exposição de dado sensível.

rest json-schema owasp rfc-9457
Performance · k6
Carga sob restrição regulatória

Cenários de carga com thresholds, modelados sob restrições de LGPD e integrados ao pipeline de CI.

k6 performance lgpd ci
